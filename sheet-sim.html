Skilling Trials — Fixed Assignment Simulator

Loads a Google Sheet's Skilling Trials tab and simulates the assignment already entered in columns A–D (from row 7) — one trial per column. It runs the exact rosters in the sheet; it does not optimize or move anyone.

← Back to the optimizer

1. Sheet source

The sheet must be shared as “Anyone with the link can view”. Reads the player grid (all 10 skill levels) and the four trial columns A–D (cells like Name · level, from row 7 down).
