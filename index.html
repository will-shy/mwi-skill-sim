Each member is simulated with their own gear, so they have their own interval and expected progress rate: rate = successRate × (1 + doubleChance) × progressPerAction / interval. A tier's time is requiredWork / Σrate; required work per tier = multiplier × roomLevel × (1 + 1% × roster). Success rate is recomputed each tier as the room level changes. This is a deterministic expected-value model — real play varies slightly around it.

4. Guild Buildings
